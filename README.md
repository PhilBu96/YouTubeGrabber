# YouTube Downloader (.NET)

## Overview

This is a small .NET application I developed some years ago, originally designed to download YouTube videos for offline use.

At the time of development, the application worked as intended and provided a simple way to retrieve video content locally.

## Current Status

YouTube has significantly changed its platform and internal mechanisms since this project was created.  
As a result, ***the application is no longer functional in its current state.***

## Maintenance

***This project is no longer actively maintained and will not receive further updates.***

## Legal Considerations

Due to the nature of YouTube content handling and changing platform policies, I have decided not to continue development of this tool.  
I prefer to focus on projects that are clearly within legal and platform-compliant boundaries going forward.

## Purpose of This Repository

This repository is kept public purely as a historical reference and showcase of earlier development work.
